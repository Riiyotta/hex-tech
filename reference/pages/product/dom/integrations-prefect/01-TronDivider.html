How it works

The prefect-hex package lets Prefect users easily create flows that trigger runs of or access metadata about Hex apps.

Including Hex in your data pipelines and orchestration workflows lets you do things like:

- Trigger a Hex app to update cached values after an upstream transformation completes - Run a Hex project with passed-in input parameters based on a form submission in another app - Automatically kick off a model re-run through Hex when new source data lands

_The prefect-hex package is created and supported by Prefect. Please file issues and report bugs directly on the GitHub repo._
