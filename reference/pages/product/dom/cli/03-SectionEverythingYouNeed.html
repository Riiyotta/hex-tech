Everything you need to control Hex with code

Create & manage projects

Spin up Hex projects in seconds. Use hex project, hex app, and hex cell to build analyses from your terminal — and make changes across many projects in one scripted pass.

Run & validate

Execute projects and apps programmatically with hex run. Integrate it into CI pipelines to catch errors and keep analyses in sync with changes to your business.

Put the agent to work

Kick off the Hex Agent from where your team already works. Use hex thread to ask a question, run the analysis in Hex, and bring the answer back into your existing workflow.

Keep context up to date

Keep your context in line with how the business evolves. Use hex guide to manage business logic and hex context to preview and publish changes to guides and semantic models.
